# Trabajo Práctico de JavaScript

Este proyecto contiene ejercicios prácticos de JavaScript enfocados en:

- Declaración y uso de **variables**
- Manipulación de **arrays**
- Creación y uso de **funciones**

Autor: **Luchiano Guiot**

## Requisitos

- Visual Studio Code
- Node.js (opcional, para ejecutar el código con Node)

## Instrucciones para clonar el repositorio

1. Abrí Visual Studio Code.
2. Presioná `Ctrl + Shift + P` y escribí `Git: Clone`.
3. Pegá la URL del repositorio (ejemplo: `https://github.com/LuchiGuiot/practicaArraysFunciones`).
4. Seleccioná una carpeta donde guardar el proyecto.
5. Abrí la carpeta en VS Code si no se abre automáticamente.
